# Working preferences
For meaningful product or design decisions, confirm intent and preferences with the owner using an interactive question tool when available; continue independent work while waiting. Never treat a default selection or elapsed time as approval. Respect the owner's requested platform and privacy choices. Preserve factual distinctions between measured outcomes, self-reported estimates, and hypothetical scenarios. Keep personal or employer-sensitive data and private repository content out of public output. Validate accessibility, responsive layouts, calculation logic and links before release. The owner leads the work; agent coordination and specialist roles should be described truthfully and verified with the owner.
